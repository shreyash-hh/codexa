## 🛠 Tech Stack

- **Frontend:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Vite
- **Backend:** Django 6.0, Django REST Framework, Python 3.10+
- **Database:** SQLite (ORM-managed)
- **Analyzers:** Radon, Pylint, Bandit, Semgrep AST Engine, pip-audit
- **AI Recommendation Engine:** Google Gemini API (2.5 Flash) + Heuristic Fallback
- **Executive Reporting:** ReportLab PDF Engine
